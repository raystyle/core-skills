# 六态标记

文档事实句的认识论状态。`project check` **不强制**；写研究报告、踩坑、硬规则来源时使用。

| 态 | 标记 | 定义 |
|----|------|------|
| 实证 | `[实证: 证据]` | 跑过/查过，证据在文档里 |
| 推断 | `[推断: 据 X 推得]` | 从已证事实推出 |
| 经验 | `[经验: 日期 场景]` | 踩过且验证过怎么修 |
| 记忆 | `[记忆: 来源]` | 会话或既成规范，能回看 |
| 假设 | `[假设: 待验证]` | 尚未支撑的主张 |
| 直觉 | `[直觉]` | 无出处倾向，不作决策依据 |

```markdown
- `uv sync` 后出现 `.venv/`。[实证: 本机 uv 0.12]
- 别名未接上是因为 Windows 联接失败。[推断: 据 hooks install 输出推得]
```

不要用「实测」修辞却不给证据。不要把参数化知识标成实证。
